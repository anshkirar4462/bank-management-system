# 🏦 Bank Management System

A simple and user-friendly **Bank Management System** developed using **Python and Streamlit**. The application allows users to create and manage bank accounts, deposit and withdraw money, view account details, update information, and delete accounts.

The project uses a **JSON file as a lightweight database** for storing account information.

---

## 🚀 Features

- 🏦 Create a new bank account
- 🔐 Secure PIN handling using hashing
- 💰 Deposit money
- 💸 Withdraw money
- 👤 View account details
- ✏️ Update account information
- 🗑️ Delete bank account
- 💵 Check account balance
- 📧 Email validation
- 🔢 Automatic account number generation
- 💾 JSON-based data storage
- 🌐 Interactive web interface using Streamlit
- ⚠️ Input validation and error handling

---

## 🛠️ Technologies Used

- **Python**
- **Streamlit**
- **JSON**
- **OOP (Object-Oriented Programming)**
- **SHA-256 Hashing**
- **Git & GitHub**
